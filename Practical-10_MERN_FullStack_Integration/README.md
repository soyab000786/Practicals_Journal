# Practical 10: Complete MERN FullStack Integration

## 🎯 Practical Objective
Develop a complete, production-ready **MERN Stack application** integrating:
1. **React.js Frontend**: Interactive User Interface, state management, and real-time inventory calculation.
2. **Express.js Backend**: REST API endpoints for full CRUD operations.
3. **Node.js**: Server runtime environment.
4. **MongoDB**: NoSQL cloud/local database managed via Mongoose ODM.

---

## 🚀 How to Run Locally
```bash
cd Practical-10_MERN_FullStack_Integration
npm install
node server.js
```
Open [http://localhost:5000](http://localhost:5000) or test via Apache [http://localhost/Practicals_Journal/Practical-10_MERN_FullStack_Integration/](http://localhost/Practicals_Journal/Practical-10_MERN_FullStack_Integration/).
