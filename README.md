## 🚀 How to Run Locally

### 1. In Browser / XAMPP Apache:
- Open URL: `http://localhost/Practicals_Journal/`
- Or directly open `index.html` in any browser.

### 2. In Terminal via Node.js / npm:
- For Frontend Practicals (1 to 4):
  ```bash
  cd Practical-01_React_Functional_Components
  npm install
  npm run dev
  ```
- For Backend Practicals (5 to 7):
  ```bash
  cd Practical-05_Express_CRUD_Routing
  npm install
  node server.js
  ```
