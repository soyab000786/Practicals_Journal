### 🚀 How to Run Locally

#### Option 1: Live Interactive Browser View (Apache XAMPP)
1. Place this directory inside `C:\xampp\htdocs\Practicals_Journal`.
2. Start Apache via XAMPP Control Panel.
3. Open in browser: `http://localhost/Practicals_Journal/`
*(Every single practical is configured with dual-mode execution to run seamlessly both via standalone browser CDN and Node.js servers).*

#### Option 2: Run Individual Node.js / Express Servers
```bash
# Example: Running Practical 08
cd Practical-08_Express_Routing_Middleware_Request_Handling
npm install
node server.js

# Example: Running Practical 10 MERN Full-Stack
cd Practical-10_MERN_FullStack_Integration
npm install
node server.js
```
