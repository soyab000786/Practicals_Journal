Employee Management API with MongoDB Atlas

Mongoose ODM, Schema Validation, Aggregation Analytics & Cloud Database Integration

🗄️ MongoDB Atlas Integration Details

Configure your MongoDB Atlas cluster connection string in .env. Run npm run seed to populate sample records, and node server.js to start the server.
