# Practical 13: Mini Project - Document Management System (DocuVault DMS)

## 🎯 Practical Objective
Design and develop a full-stack, industry-oriented **MERN Application (Document Management System)** with:
- Multi-tier document archival with access-level protection (Public, Internal, Confidential).
- Departmental segregation (Engineering, Legal, Finance, Academic, HR).
- Search, filter, versioning, and download counters.
- Automated Audit Trail logging of every creation, access, and deletion event.
- Live administrative telemetry and storage metrics dashboard.

---

## 🚀 How to Run Locally
```bash
cd Practical-13_Mini_Project_Document_Management_System
npm install
node server.js
```
Open [http://localhost:5000](http://localhost:5000) or test via Apache [http://localhost/Practicals_Journal/Practical-13_Mini_Project_Document_Management_System/](http://localhost/Practicals_Journal/Practical-13_Mini_Project_Document_Management_System/).
